## 同机联网结果

- 直连：原有和延长等待均失败；最终报告里 16 次直连请求收到的文件数据合计为 0 字节。
- HTTP 代理：最终首段对照的 16 次请求全部成功。
- 通过代理完整下载并校验过的软件完整包、一个代表性增量文件、常用依赖包、抓包依赖包，共 4 个文件均通过文件指纹校验。没有重复下载整包来比较两套超时；下载的临时文件已清理。

| 完整文件 | 接收字节数 | 完整请求耗时 |
| --- | ---: | ---: |
| 代表性增量文件 | 10,222,178 | 5.953 秒 |
| 软件完整包 | 66,810,866 | 30.594 秒 |
| 常用依赖包 | 164,146,362 | 63.516 秒 |

较长等待下，Qt 更新清单和目录探测约 29 秒后返回未知网络错误 99，没有收到文件内容；工具没有猜测具体原因。Requests 探测约 15～17 秒就报告连接超时，虽然设定的允许时间更长。

报告位于源码目录下的 build/network-probes：

- direct-final.json：最终版直连首段报告。
- proxy-final.json：最终版代理首段报告。
- proxy-validation.json：4 个完整文件的下载与校验证据。
- direct-validation.json：最初一轮直连记录。

最初报告保留了当时实际使用的参数。工具随后校准了原有目录检查的重置时限与离线整包的总时限；成功的完整下载均未触及这些总时限。

## 目前能得出的结论

本机结果不支持直接把问题认定为“超时太短”，应继续查直连线路以及浏览器与软件的网络差异。这不能证明 Cloudflare 全球服务故障，也不能解释客户另一台电脑的网络情况。

客户电脑及网络尚未实际验证；需要在那里按中文使用说明复测。本次没有验证 Debian 运行，也没有进行路由器操作。
