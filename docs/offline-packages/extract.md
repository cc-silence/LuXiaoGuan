# 提取离线依赖

常用依赖、抓包依赖两张离线包卡片共用“提取依赖”入口，不需要连接路由器或联网。

1. 点击后在后台校验本地签名和清单。
2. 依次选择准确的 OpenWrt 版本、固件平台、处理器架构。仅列出本地清单中真实存在的组合；IPK/APK 格式由组合自动确定。
3. 多选主依赖，或使用全选、全不选。
4. 选择电脑上的保存位置。软件新建独立目录，输出原始名称的包以及配套依赖，同时写入 export.json 和“依赖清单.txt”。

提取复用构建离线包的正向依赖图选择逻辑，支持普通 IPK 依赖、候选依赖、虚拟提供者以及 APK 结构化依赖；不把负依赖当作需要安装的包。固件自带的基础组件在清单中单独注明，不从通用包导出替换。

资源和目标文件均校验完整性；导出期间资源版本变化会要求重新选择。原离线包不改名、不移动，导出不覆盖已有目录。取消、失败、校验错误时移除本次未完成的私有临时目录。提取任务有总时限，复用常驻后台任务和公共任务进度弹窗；退出软件请求取消并等待任务回收。

模块分工：
- bundle_dependencies：构建器和运行时共用的依赖图。
- bundle_export：本地清单筛选、逐块校验复制和结果清单。
- BundleExportService：后台任务、进度、取消。
- BundleExportDialog / BundleExportActions：级联筛选与非阻塞窗口生命周期。

提取成功表示文件已按清单校验并输出，不表示已经在路由器安装或完成真机功能验收。

## 本轮验证

- 定向回归 80 项通过，另补充完整界面到导出的后台交接测试 1 项通过。
- 使用本地留存的正式签名和 ZIP 文件，验证两种依赖包、六个 OpenWrt 系列共 12 次真实文件导出，包含 IPK 与 APK。
- 对正式清单的 1,183 个适配组合、10,856 次单主依赖选择核对配套依赖闭包。
- 明暗主题、100% / 150% 缩放实际绘制检查通过；导出只处理电脑文件，不涉及路由器安装或真机功能验收。
