# 常用设置图标

本目录存放常用设置列表使用的系统工具图标，优先使用彩色、渐变的 Windows 工具图标。

- 来源：https://github.com/microsoft/PowerToys/tree/main/doc/images/icons
- 项目许可证：详见同目录 `POWERTOYS_LICENSE.txt`
- 补充来源：https://icons8.com/icons/fluency
- Icons8 图标使用时需要按其许可要求提供署名；本目录中的 `System *.png` 为 Windows 11 Color / Fluent 风格 PNG，覆盖文件、网络、安全、磁盘、电源和系统维护类别。
- 格式：PNG

添加或编辑快捷入口时，点击“选择图标”即可从这套图标中选择。目标脚本、程序和图标文件不会因配置保存而被复制或覆盖。
